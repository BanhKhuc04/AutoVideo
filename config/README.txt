===============================================================
YouTube Clip Studio Pro - Phiên Bản Portable (Không Cần Cài Đặt)
===============================================================

HƯỚNG DẪN SỬ DỤNG:
1. Giải nén toàn bộ thư mục ZIP này vào bất kỳ vị trí nào (Ổ C, D hoặc USB).
2. Nhấp đúp vào file "YouTubeClipStudio.exe" để chạy ứng dụng ngay lập tức.
3. Ứng dụng sẽ tự động khởi động server xử lý video ngầm mà không cần cài đặt Node.js hay FFmpeg.

CẤU TRÚC THƯ MỤC PORTABLE:
- YouTubeClipStudio.exe : File chạy chính của ứng dụng
- resources/bin/        : Chứa công cụ yt-dlp.exe và ffmpeg.exe
- config/               : Chứa cấu hình cá nhân
- data/                 : Lưu trữ dữ liệu và cài đặt di động (tự động tạo khi chạy)
